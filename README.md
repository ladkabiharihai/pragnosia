# Pragnosia

A **growing recurrent brain** that learns by pure local plasticity (no backprop), not another LLM.
Continually learning, stateful, grows from infant, efficient like a brain.

- **VISION.md** — the full design (foundational principles, architecture, learning, growth, memory, continual learning).
- **PROGRESS.md** — experiments and results log.

Not affiliated with any LLM benchmark race: we compete on **efficiency x continual learning x long/unbounded context**,
at tiny cost. Author: Ashish Kumar.
