# Session memory, mirrored

These files are the assistant's persistent memory for this project, normally held at
`~/.claude/projects/-opt-code-membrae/memory/`. They are mirrored here so that the machine
holding them can be lost without losing them: the server is not the record, the repository is.

`MEMORY.md` is the index loaded at the start of every session; the other files are one fact each.
To restore, copy them back to that path.

CONSTRAINTS.md and VISION.md at the repository root are the substantive record and take precedence;
these notes only carry what a fresh session needs to know before reading them.
